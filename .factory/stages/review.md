# Review guidelines for danysbees

These add to the factory's review guidelines.

| Rule | Blocks on |
|---|---|
| I18N | New or changed text missing from any of `src/i18n/en.json`, `fr.json` or `ar.json`, or text written straight into a page instead of through the translation files |
| PATTERN | A new section that doesn't follow an existing one on the site, for example a FAQ that doesn't reuse the tours FAQ structure |
| RTL | Layout that would break right to left in Arabic, such as left/right spacing where start/end is needed |
