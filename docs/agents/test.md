# Test guidelines for danysbees

These add to the factory test guidelines.

- The site has no test script: run `npm run build` and check it completes for all pages.
- Preview locally with `npm run preview` after the build.
- Screenshot every changed page in all three languages: `/en/…`, `/fr/…` and `/ar/…`.
- Check the Arabic pages read right to left and nothing overlaps or gets cut off.
- Take every screenshot at both sizes: laptop (1440×900) and mobile (iPhone 14). Most visitors are on phones, so check the mobile ones closely.
